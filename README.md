<h1>Ingatku, Version 1.0</h1>
<h2>Overview</h2>
<p></p>
Ingatku is an app which lets you add your Groceries, Project and Daily Tasks in a reminder, so you can add when to start and when to end (make sure your notification for this app is enabled.) and also add description and checklist for your tasks. You can also colour code your tasks so you can differentiate which tasks is for what category

Ingatku also provides a notes section, which you can type and think what do you want to add for your future tasks.
